# 3D五目並べ

重力あり・ひっくり返しあり の 3D 五目並べ。Three.js 製、ブラウザで動作。

## 遊び方

| 操作 | 内容 |
|------|------|
| `←` `→` `↑` `↓` | ゴーストカーソル移動（X/Z方向） |
| `Space` or `Enter` | 石を落とす |
| マウスドラッグ | 3D視点を回転 |
| マウスホイール | ズーム |
| **ひっくり返す**ボタン | 盤面を上下反転（各プレイヤー1回限り） |

## ルール

- **8×8×8** の3D盤面、重力あり（石は落下）
- **4つ**縦・横・斜め・対角（空間斜め含む）に揃えた方が勝ち
- 「ひっくり返す」で盤面を反転 → 石が再落下
- ひっくり返した際に両者同時に揃った場合 → **発動した側の勝利**
- 揃った石は赤くハイライト

## ファイル構成

```
index.html          エントリポイント
css/style.css       スタイル（ダークサイバー風）
js/game.js          ゲームロジック（重力・フリップ・勝敗判定）
js/renderer.js      Three.js 3D描画
js/cpu.js           CPU（現在ランダム、将来AI強化予定）
js/main.js          イベント管理・ゲームフロー
```

## GitHub Pages で公開

1. このリポジトリを GitHub に push
2. Settings → Pages → Source: `main` ブランチ `/root` に設定
3. 公開URLにアクセスして完了
